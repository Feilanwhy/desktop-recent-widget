# 桌面玻璃小部件

一个挂在桌面上的玻璃透明小部件：按时间从新到旧显示最近打开的文件/软件，双击即可直接打开。

## 功能

- **iOS 液态玻璃外观**：无边框、圆角，半透明白渐变玻璃质感（上亮下暗），带顶部高光和柔光斑，桌面内容透过玻璃微微可见
- **最近记录**：读取 Windows「最近访问」记录（`%APPDATA%\Microsoft\Windows\Recent`）；用文件系统监听实时刷新，打开文件后几乎立刻出现，另有 30 秒兜底刷新
- **双击打开**：双击任意条目直接打开对应的文件或软件；单击只做选中，不会打开
- **锁开关**：顶部右侧第一个按钮（锁形）。点击上锁后，再双击任何条目都不会打开，锁变黄色；再点一次解锁
- **关闭按钮**：锁按钮右边的 X，点击关闭小部件
- **自由调整大小**：拖动小部件的边缘或四角即可缩放，和普通窗口一样（悬停到边缘时光标会变成缩放箭头）
- **自由移动**：**按住鼠标右键，在小部件任意区域拖动即可换位置**（最方便）；也保留顶部三横线把手、标题行、列表空白处拖动
- **钉子固定**：右上角钉子图标，点击固定位置（固定后不能拖动/缩放），再点解除；状态自动记住
- **记忆位置**：位置、大小、锁定、固定状态都会自动保存，下次启动恢复
- **开机自启**：双击 `开机自启-开启.bat` 一键开启（之后每次开机自动出现），`取消开机自启.bat` 一键取消

## 使用

1. 双击 `start.bat` 启动小部件（无命令行窗口，静默运行）
2. 想开机自动启动：双击 `开机自启-开启.bat`，之后每次开机自动运行；
   想取消就双击 `取消开机自启.bat`（或手动：按 `Win + R`，输入 `shell:startup`，回车，删除里面的“桌面最近打开小部件”快捷方式）

## 待办便签（第二个小部件）

项目里还附带一个独立的**待办便签**小部件（`todo_widget.py`）：
双击空白处添加待办，点左侧圆圈勾选完成（文字划线），点右侧 X 删除，双击条目编辑，内容自动保存。
启动：双击 `待办便签-start.bat`；开机自启用 `待办便签-开机自启-开启.bat`。

## 退出

小部件没有窗口边框，退出方式：

- 点击小部件右上角的 **X 按钮** 直接关闭
- 或在任务管理器 →「详细信息」里找到 `pythonw.exe`（或 `python.exe`）结束进程
- 或在命令行执行：`taskkill /f /im pythonw.exe`（注意：这会结束所有 pythonw 进程）

## 依赖

- Python 3.9+
- PySide6（`python -m pip install PySide6`）

## 常见问题

- **列表是空的**：Windows 只在通过资源管理器/标准打开方式打开文件时记录「最近访问」。先正常打开几个文件，会自动出现；也可以检查 `%APPDATA%\Microsoft\Windows\Recent` 里有没有 `.lnk` 文件。
- **白色文字在亮色壁纸上可能看不清**：背景完全透明时文字没有底色衬托，如果壁纸很亮，可以换深色壁纸，或告诉我给文字加一层淡淡阴影。
